# ADR 001: PostgreSQL 데이터베이스 선택

## 상태
Accepted

## 날짜
2024-12-21

## 맥락
영어 교육 플랫폼의 데이터 저장소 선택이 필요함.
- 사용자 정보, 도서, 챕터, 퀴즈 등 관계형 데이터 저장
- 학습 진도, 사용자 설정 등 JSON 형태 데이터도 필요
- 서버리스 환경(Vercel/Railway) 배포 고려
- 1인 개발 프로젝트로 관리 용이성 중요

## 고려한 옵션들

### 옵션 1: PostgreSQL
- 장점: 
  - JSONB로 JSON + 관계형 동시 처리 가능
  - 풍부한 생태계와 안정성
  - Railway 내장 지원
  - 무료 호스팅 옵션 풍부 (Supabase, Neon, Railway)
- 단점: 
  - 초기 설정이 MongoDB보다 복잡

### 옵션 2: MongoDB
- 장점: 스키마 유연성, JSON 저장 최적화
- 단점: 관계형 쿼리 어려움, 트랜잭션 제한적

### 옵션 3: SQLite
- 장점: 파일 기반으로 간단, 배포 쉬움
- 단점: 동시성 제한, 서버리스 확장성 부족

## 결정
**PostgreSQL** 선택

이유:
1. 도서-챕터-퀴즈 관계를 효율적으로 표현 가능
2. Railway에서 내장 PostgreSQL 제공
3. Connection Pooling으로 서버리스 환경 최적화 가능
4. pg 라이브러리의 안정성과 성숙도

## 결과

### 긍정적
- 하나의 DB로 모든 데이터 타입 처리 가능
- 복잡한 조인 쿼리 성능 우수
- 트랜잭션 지원으로 데이터 무결성 보장

### 부정적
- Cold start 시 연결 지연 가능성
- 연결 풀 관리 필요

### 리스크
- 서버리스 환경에서 Connection Pool 고갈 가능
  → 해결: max/min 설정 및 keepAlive 옵션 적용 완료
